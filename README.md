# RecipeBox 🍳

Buscador de recetas de cocina con sistema de favoritos, filtros por etiquetas y búsqueda inteligente.

## Características

- Base de datos de 12 recetas internacionales
- Búsqueda por nombre o ingrediente
- Filtrado por etiquetas (italiana, japonesa, vegana, etc.)
- Sistema de favoritos con persistencia en localStorage
- Vista detallada con ingredientes y pasos
- Diseño oscuro premium con emojis temáticos
- Responsive y mobile-first

## Demo

Abre `index.html` en tu navegador. No requiere servidor ni instalación.

## Uso

1. Explorá las recetas en la vista principal
2. Usá la barra de búsqueda para encontrar recetas específicas
3. Filtrá por etiquetas (italiana, mexicana, saludable, etc.)
4. Hacé click en una receta para ver detalles completos
5. Marcá favoritos con el botón ❤️
6. Cambiá a la vista "Favoritos" para ver tus recetas guardadas

## Estructura

```
.
├── index.html   # Layout, grid de recetas, modales
├── styles.css   # Tema oscuro premium, cards, filtros
├── app.js       # Base de datos, búsqueda, favoritos
└── README.md    # Este archivo
```

## Stack

HTML5 + CSS3 + JavaScript ES6+ (vanilla). Sin dependencias externas. Persistencia en localStorage.
